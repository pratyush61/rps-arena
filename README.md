# RPS Arena — Rock Paper Scissors

A responsive browser-based Rock Paper Scissors game where you play against the computer, view the round result, and track your scores.

## Live Demo

_Add your deployed URL here after publishing the project with GitHub Pages or another static hosting provider._

## Features

- Play Rock Paper Scissors against a computer-generated choice.
- View the round outcome and score.
- Open a rules dialog while playing.
- Responsive layout for desktop and mobile screens.
- Interactive choice states and visual feedback.

## Built With

- HTML5
- CSS3
- Vanilla JavaScript

## Run Locally

1. Clone your repository:
   ```bash
   git clone https://github.com/pratyush61/rps-arena.git
   ```
2. Open the project folder:
   ```bash
   cd rps-arena
   ```
3. Open `index.html` in your browser. No build step or package installation is required.

You can also use VS Code with the Live Server extension to run it locally.
